# Notes for Claude Code

## Only the tasks I ask for
Don't create anything that runs or shows up later unless I've asked for it in my own words: no routines or
scheduled triggers, no send_later reminders or self check-ins (including the safety-net check-ins on PRs), no
suggested-task cards (spawn_task), no loops or cron jobs. If one seems useful, ask me in a sentence and leave it
at that. Watching a PR for CI and review events is fine; scheduling check-ins on it is not.

See REVIEW.md for how changes are reviewed, and update changes.json with every change.
